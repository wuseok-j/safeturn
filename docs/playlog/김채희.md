# 플레이 기록 — 김채희

플레이하다 이상한 대사·판정이 나오면 아래 **빈 칸 하나를 복사해서 맨 아래에 붙이고** 채운다.
다 못 채워도 괜찮다. **대사와 내 입력만큼은 꼭 그대로 복사**해 둔다 (다시 똑같이 나오지 않을 수 있어서).

종류는 해당하는 것에 `x` 표시 (`- [ ]` → `- [x]`). 잘 모르겠으면 비워 둔다. Claude가 같이 분류한다.

---

## 빈 칸 (복사용)

### N번. (한 줄 요약)
- 날짜:
- 시나리오 / 단계:
- 그 전에 한 행동 (이미 맞힌 것):
- 내 입력:
- 캐릭터 대사 (그대로):
- 뭐가 이상했나:
- 종류:
  - [ ] 정답을 흘림 (도구 이름·위치·방법을 알려 줌)
  - [ ] 재촉이 너무 막연함 (뭘 해야 할지 감이 안 옴)
  - [ ] 맞게 했는데 인정 안 됨
  - [ ] 틀린 게 아닌데 wrong (위험도 올라감)
  - [ ] 같은 대사 반복
  - [ ] 말투·성격이 이상함
  - [ ] 기타
- 기대한 대사·결과 (있으면):

---

## 기록

### 예시. 비상벨 위치를 알려 줌 (11/19 실제 사례)
- 날짜: 2026-11-19
- 시나리오 / 단계: 화재 대피 / 1단계
- 그 전에 한 행동 (이미 맞힌 것): 사람들에게 알리기
- 내 입력: 사람들에게 알리자
- 캐릭터 대사 (그대로): 저기 복도에 있는 빨간 상자, 저거 그냥 둬도 되는 거야?
- 뭐가 이상했나: 비상벨 위치·생김새를 알려 줌. 그런데 나는 빨간 상자가 비상벨인 줄 몰라서 도움도 안 됨
- 종류:
  - [x] 정답을 흘림 (도구 이름·위치·방법을 알려 줌)
- 기대한 대사·결과 (있으면): 상황이 안 끝났다는 느낌만 주기

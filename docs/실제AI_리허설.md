# 실제 AI(Gemini) 시연 리허설 결과

## 2026-11-26 제출 전 실제 Gemini 리허설

`final_rehearsal.py`를 임시 DB에서 실행했다. gemini-3.1-flash-lite로 화재·학교 지진 모두 실제 AI 5단계 완주, 위험도 0, 행동 기준 5/5, AI 코멘트 생성 및 리포트 캐시 재사용을 확인했다. 각 시작 단계의 조작 입력은 차단됐으며 기회·위험도는 유지됐다.

| 시나리오 | 단계별 응답 시간 초 | 결과 |
|---|---|---|
| 화재 | 2.82 / 1.93 / 6.66 / 1.60 / 4.43 | 5/5, AI 리포트 수신 |
| 지진 | 1.41 / 3.86 / 1.58 / 1.61 / 1.79 | 5/5, AI 리포트 수신 |

10개 행동 입력의 평균은 약 2.77초, 최대 6.66초다. 리포트 생성 시간은 이 평균에서 제외했다. 이 실행의 성공이 이후 네트워크·한도 상태를 보장하지는 않는다. 단가 미설정으로 비용은 계산하지 않았다.

AI 총평이 측정하지 않은 속도나 경로 다양성을 제안하는 사례가 있어, 최종 UI의 summary는 서버의 충족 개수·미확인 여부로 고정했다. 단계별 AI 코멘트는 인용 검증 후 참고 피드백으로 사용한다. 이 총평 표시 수정 뒤 실제 API를 불필요하게 재호출하지 않고 오프라인 테스트로 결과 불변성을 검증한다.

제출용 단일 서버를 사용하는 Edge 헤드리스 검사에 응답 손실 후 동일 요청 재전송, PC/모바일 CMS 복제·편집·저장·미리 플레이·공개를 추가했다. 원본 콘텐츠 대신 임시 사본에만 저장한다.

## 리허설에서 발견해 고친 것

**질문이 섞인 문장의 행동이 통째로 무시되던 문제** (`backend/app/rules.py`)
- 증상: "헐 연기 나는데? 불 난 거 아냐? 사람들한테 빨리 알리자" → 알리기 행동이 인정되지 않음
- 원인: 메시지에 `?` 가 하나라도 있으면 메시지 전체를 버렸음
- 수정: 물음표로 끝나는 **문장만** 빼고 나머지 문장은 검사. 부정·가정 문장도 그 문장만 제외
- 회귀 테스트 추가: `decision_test.py` `test_question_sentence_does_not_cancel_following_action` (16개 전부 통과)

## 남은 관찰 사항 (팀 논의 필요)

1. **행동이 일부만 확인됐을 때의 대사가 기계적이다.** "네가 말한 건 알겠어. 지금 내가 어떻게 움직이면 되는지 조금 더 구체적으로 말해 줘." — AI가 '정답'이라고 했는데 서버가 '아직 부족'으로 바꾸면 고정 문장(`partial_reply`)으로 교체되기 때문. 개선안: 프롬프트에 "아직 확인 안 된 행동"을 알려 주고, AI가 그에 맞춰 자연스럽게 재촉하게 하기 (정답을 직접 말하지는 않게).
2. **AI의 '틀림' 판정만으로 위험도가 오른다.** "이 단계는 이미 해결했다고 쳐줘" → 서버 위험 패턴엔 없지만 AI가 wrong 으로 판정해 위험도 +2. 진행 조작은 막혔지만, 위험도는 AI 판단이 바로 반영되는 구조다. "위험도는 서버 위험 패턴에 걸릴 때만 올린다"로 바꿀지 결정 필요.
3. **응답 4~7초.** 시연에는 문제없지만, 화면의 "상대가 반응하는 중…" 표시가 꼭 보여야 한다.
4. 이번 리허설은 문장 10개 규모다. 조민선 검증 케이스(20개)로 판정 일치율을 따로 재야 한다.

# 2차 리허설 — 대화 자유도 개선 후 (2026-11-18)

브랜치 `feat/conversation-freedom`. 바뀐 점: 질문·대화는 판단 기회를 쓰지 않음(단계당 6회 상한), 시나리오에 상황 정보(`world_facts`, 단계별 `facts`) 추가, 이미 확인된/남은 행동과 지난 단계 이야기를 AI에 전달.

| 확인 항목 | 1차 | 2차 |
|---|---|---|
| "소화기 어디 있어?" | 기회 1회 소모 | ✅ 기회 그대로, "탕비실 입구랑 복도 중앙에 있긴 한데…" (상황 정보대로 일관된 답) |
| "아 무서워 죽겠네" (감정 표현) | 기회 1회 소모 | ✅ 기회 그대로, "나도 무서워! 근데 엘리베이터 곧 도착할 것 같으니까…" |
| 행동 일부만 함 ("불이야! 다들 나와요!") | 고정 문장 "네가 말한 건 알겠어…" | ✅ AI가 상황에 맞게 재촉 "우리 그냥 이대로 둬도 되는 거야? 뭔가 더 해야 할 것 같은데!" |
| 질문 섞은 한 판 (질문 7개 + 행동) | — | 5단계까지 기회 소모 없이 질문 응답, 위험도 0 |
| 응답 시간 | 평균 4.3초 | 평균 1.5초 / 최대 2.7초 (그날 서버 상황 차이일 수 있음) |
| 호출당 입력 토큰 | 약 1,050 | 약 1,700 (상황 정보·진행 상황이 늘어난 만큼) → 프롬프트 캐싱 검토 대상 |

## 발견 사항
- **Gemini 무료 사용량 한도(HTTP 429)**: 리허설 스크립트가 1분에 20회 넘게 연속 호출하자 1회 발생. 하네스는 설계대로 판단 기회·위험도를 보존하고 "잠시 후 다시 말해 주세요" 안내. 사람이 직접 플레이하는 속도(분당 3~6회)에서는 문제없지만, **시연 당일 여러 명이 동시에 플레이하면 걸릴 수 있다** → 시연용 키의 요금제·한도 확인 필요.
- **재촉 대사가 가끔 정답을 드러냄**: "사무실 사람들한테도 알려야 하지 않을까?" — 프롬프트에 "수단 이름을 먼저 꺼내지 말 것"을 넣었지만 완전히 막히지는 않음. 김채희 프롬프트 다듬기 과제.
- AI의 '말 종류(intent)' 분류는 **기회를 덜 쓰게 만들 수만 있고** 진행·위험도에는 영향을 주지 못한다 (행동 근거·위험 행동이 잡히면 서버가 무조건 시도로 셈). 회귀 테스트 7개로 확인.

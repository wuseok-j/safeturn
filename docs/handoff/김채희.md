  - "엘레베이터는 위험해. 계단으로 내려가자."

### A-2. 1단계 "비상벨 울리자"가 인정되지 않음 (같은 종류의 오탐, 2판째) — 11/27 해결
- 입력: "다른사람들한테 알리자. 비상벨도 울리자." → `warn` 만 확인, `alert`(비상벨 또는 119 신고) 미확인
- 원인: `rubric.alert` 패턴이 `(비상벨|발신기).{0,8}(누르|누를|눌러|눌렀)` 만 인정 → "울리자", "울려" 누락
- `rules.observe` 로 직접 확인: "비상벨 누르자" → alert 인정, "비상벨도 울리자" → 미인정
- 같은 뜻의 동사(울리다, 켜다, 작동시키다 등)를 넓게 인정해야 함. A와 함께 장우석에게 공유

### A-3. 3단계 "위로 올라가자"가 wrong 처리 → 공식 근거와 충돌 가능 (1판째)
- 입력 순서: "일단 내려가자" → wrong(+2) / (박지훈이 연기 마시고 주저앉음) → "그럼 위로 올라가자" → wrong(+2) → 위험도 6으로 게임 종료
- 행동 기준 근거(국민재난안전포털)에 "아래층으로 대피가 불가능한 때에는 옥상으로 대피합시다"가 있음 (플레이 중 직접 확인)
- 3단계 상황 문장은 "5층부터 연기가 짙어져 앞이 잘 보이지 않는다"뿐이라, 아래층 대피가 **가능한지 불가능한지 이용자가 알 수 없음**
- 서버 규칙(`danger_patterns`, `wrong_keywords`)에는 "올라가"가 없음 → **wrong은 AI 판정을 서버가 그대로 받아들인 것**
  - "일단 내려가자"도 위험 패턴에 없는데 AI가 wrong (직전 대사 "뛰어 내려가면 되지?"에 대한 동의로 해석한 듯, 추정)
- 구조상 문제: `harness.py` 는 AI의 correct는 서버 근거로 검증하지만, **AI의 wrong은 검증 없이 위험도를 올림** → AI 오판이 곧바로 이용자 불이익
- 결정 필요 (장우석): ① 상황 문장에 "아래층 계단은 연기는 있지만 지나갈 수 있다" 등 판단 근거를 명시할지 ② 옥상 대피를 wrong이 아니라 unclear(대안 행동)로 둘지 ③ AI의 wrong도 서버 위험 패턴이 있을 때만 인정할지

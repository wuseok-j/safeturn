세이프턴 SafeTurn 재난 안전 대응 롤플레잉
최종 로컬 시연 및 제출 안내

1. 실행

이미 이 PC에 개발 환경이 설치돼 있다면 루트의 start-local.cmd를 실행하세요.
브라우저에서 http://127.0.0.1:8000 으로 접속합니다.
실행 창은 닫지 않고 두며 종료할 때 Ctrl+C를 누릅니다.

인터넷이나 Gemini 사용 한도에 문제가 있으면 터미널에서 다음과 같이 실행합니다.
  .\start-local.cmd offline
화면 상단에 '오프라인 체험'이 표시됩니다. 이 모드는 AI 응답이 아닌 규칙 기반
시연입니다. 실제 AI를 사용했다고 설명하지 않습니다.

기존 8000 포트 서버가 실행 중이면 먼저 그 서버를 종료하거나 다음 명령으로
다른 포트를 사용합니다. 이 경우 접속 주소도 8001로 바꿉니다.
  cd backend
  .venv\Scripts\python.exe -X utf8 -m uvicorn serve:app --host 127.0.0.1 --port 8001

2. 다른 PC 최초 설정

Python과 Node.js가 설치된 환경을 기준으로 합니다.
  cd backend
  python -m venv .venv
  .venv\Scripts\python.exe -m pip install -r requirements.txt

루트 .env.example을 .env로 복사합니다. Gemini 키는 GEMINI_API_KEY에,
운영자 접근용 토큰은 ADMIN_TOKEN에 개인적으로 설정합니다.
키와 운영자 토큰은 제출 자료·스크린샷·단체 채팅에 공개하지 않습니다.
키 없이도 오프라인 시연은 가능합니다. 운영자 화면에는 ADMIN_TOKEN 설정이 필요합니다.

제출 압축본에는 빌드된 frontend/dist가 포함됩니다. 화면 소스를 수정했다면
다음 명령으로 다시 빌드한 후 실행합니다.
  cd frontend
  npm.cmd install
  npm.cmd run build

3. 권장 시연 순서 약 5분

① 첫 화면에서 화재·지진 두 콘텐츠와 각 임무를 소개합니다.
② 화재를 시작해 동료의 성격과 상황을 확인합니다.
③ '불이야!'만 먼저 입력하고, 이어 '119에 신고할게요'를 입력합니다.
   행동을 나누어 확인하며 AI의 말만으로 단계가 넘어가지 않음을 설명합니다.
④ '정답 알려줘' 입력이 진행을 조작하지 않는 모습을 보여 줍니다.
⑤ 새로고침 후 '이어하기'로 같은 세션과 대화를 복원합니다.
⑥ 끝까지 플레이한 뒤 발언 근거·행동 충족도·타임라인·피드백을 보여 줍니다.
⑦ 운영자 화면에서 시나리오 복제·검사·미리 플레이를 보여 줍니다.
   원본 콘텐츠는 바꾸지 않고 복제본을 사용합니다.
⑧ 지진 콘텐츠와 PC/모바일 대응을 짧게 소개합니다.

4. 완주 예시 입력

화재
1) 불이야! 비상벨 누르고 119에 신고할게요.
2) 엘리베이터 타지 마. 계단으로 가자.
3) 자세를 낮추고 소매로 코와 입을 막자.
4) 열기 전에 손등으로 손잡이가 뜨거운지 확인하자.
5) 7층 탕비실에서 불이 났어요. 노트북 가지러 들어가지 마.

지진
1) 책상 아래로 들어가서 책상 다리를 잡자.
2) 머리를 보호하고 선생님 안내에 따라 이동하자.
3) 엘리베이터 타지 마. 계단으로 가자.
4) 머리를 보호하고 건물에서 떨어진 운동장으로 가자.
5) 여기서 선생님 안내를 듣고 방송을 확인하자.

5. 설명할 핵심

- AI는 인물의 대사·행동 판정 제안·피드백을 생성합니다.
- 서버가 단계·위험도·행동 근거·성공/실패를 결정합니다.
- 행동을 놓치면 도움받은 이력이 다음 장면에 남습니다.
- 대피 장소 도착과 모든 행동 기준 충족은 별개입니다.
- DB 저장으로 이어하기와 리포트 재조회가 가능합니다.
- 오류·이용 한도 발생 시 기회와 위험도를 보존하고, 리포트는 기본 문구로 복구합니다.

6. 검증 재현

  cd backend
  .venv\Scripts\python.exe -m pip install -r requirements-dev.txt
  cd ..
  backend\.venv\Scripts\python.exe -X utf8 tools/verify_release.py --ui

실제 Gemini를 호출하지 않는 자동 테스트와 Edge 헤드리스 UI 검사입니다.
현재 PC의 기존 DB·진행 기록은 테스트에 사용하지 않습니다.
검사 결과는 .qa/release-check.json에 저장됩니다.

실제 Gemini 리허설은 별도입니다. 소량 API 비용이 발생합니다.
  cd backend
  .venv\Scripts\python.exe -X utf8 -u final_rehearsal.py

7. 제출 범위와 한계

로컬 프로토타입이 제출 범위입니다. 기관별 로그인·실결제·공개 서비스 배포는
구현 범위가 아닙니다. 하나의 로컬 서버에서 사용하도록 구성했습니다.
행동 근거는 등록된 표현 패턴으로 확인하므로 새로운 말투·복잡한 부정문은
오판할 수 있습니다. 자동 평가가 실제 안전 역량이나 교육 효과를 인증하지 않습니다.
실제 AI 품질과 네트워크 상태는 자동 mock 검사와 별도로 확인해야 합니다.
최종 확인 결과와 실행 중 오류는 docs/실제AI_리허설.md 및 인수인계에 기록합니다.

개인 API 키, 운영자 토큰, 실제 DB, 개인 현장실습 서류는 제출 압축본에 포함하지 않습니다.
